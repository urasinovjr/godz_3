# ДЗ 3. Бюджеты в сервисе Ledger

Тема ввод-вывод и обработка ошибок. Это продолжение ДЗ 2, сервисы те же самые. Gateway не менялся, а в Ledger к транзакциям добавились бюджеты.

## Что сделано в Ledger

Бюджет описан структурой `Budget`, в ней категория, лимит и период. Бюджеты хранятся в `map[string]Budget`, ключом служит название категории.

`SetBudget` добавляет новый бюджет или меняет лимит у существующего. Начальные бюджеты в `main` задаются тоже через нее.

`AddTransaction` теперь смотрит, есть ли бюджет на категорию транзакции. Если есть, она считает, сколько по этой категории уже потрачено. Когда вместе с новой тратой выходит больше лимита, транзакция не сохраняется и функция возвращает ошибку.

`LoadBudgets(r io.Reader)` читает бюджеты из JSON. В `main` файл открывается через `os.Open("budgets.json")` и `bufio.NewReader`. Если файл не прочитался или JSON кривой, функция возвращает ошибку с понятным текстом.

В `main` проверены трата в пределах лимита и трата сверх лимита, категория без бюджета, отрицательная сумма, смена лимита, загрузка бюджетов из файла и битый JSON.

Файлы в папке `ledger`:

- `main.go` - транзакции, `AddTransaction`, `ListTransactions` и проверка сценариев
- `budget.go` - бюджеты, `SetBudget`, `LoadBudgets`
- `budgets.json` - бюджеты для загрузки

## Запуск Ledger

Запускать надо из папки `ledger`, иначе программа не найдет `budgets.json`:

```bash
cd ledger
go run .
```

Программа пишет, какие транзакции добавились, а какие нет и почему. В конце печатается список из 6 транзакций, отклоненных в нем нет.

`budgets.json` это массив объектов:

```json
[
  {"category": "развлечения", "limit": 3000, "period": "месяц"},
  {"category": "транспорт", "limit": 2500, "period": "месяц"}
]
```

## Запуск Gateway

```bash
cd gateway
go run .
```

Проверить можно из второго терминала, в ответ придет `pong`:

```bash
curl http://localhost:8080/ping
```
